25. HTML, CSS y JavaScript

Cómo trabajan juntos

Una página web se construye con tres tecnologías que trabajan en conjunto. Cada una tiene un rol específico:

  • HTML Estructura

    HTML (HyperText Markup Language) crea la estructura de la página. Define el contenido y su organización: títulos, párrafos, imágenes, enlaces, formularios.

  • CSS Diseño

    CSS (Cascading Style Sheets) da estilo y diseño a la página. Controla colores, tipografías, tamaños, espaciados, posiciones y mucho más.

  • JavaScript Interactividad

    En la página, responde a acciones del usuario, modifica el contenido, valida formularios y muestra mensajes. En esta materia no lo usamos: lo vemos en Programación II.

Idea clave: la estructura (HTML), el diseño (CSS) y la interactividad (JavaScript) se complementan para crear páginas web completas.

26. El proyecto en VS Code

Carpeta, explorador, Emmet, Live Server y Prettier

Usamos el ambiente que configuraste en el TP6: el editor (VS Code), una carpeta para los archivos y el navegador (Chrome) para probar la página. Lo nuevo: ahora creamos los archivos desde cero.

Live Server

Abre la página en una dirección como 127.0.0.1:5500/index.html: es nuestra propia computadora. Para cerrarlo, tocamos el mismo botón C, que ahora dice Port : 5500.

Paso a paso

  1. 1Crear la carpeta: clic derecho → Nuevo → Carpeta. La llamamos mi-sitio.
  2. 2Abrirla en VS Code: Archivo → Abrir carpeta… Aparece en el Explorador A.
  3. 3Crear los archivos con B: index.html, styles.css y la carpeta img. Cada archivo, con su extensión.
  4. 4Probar con Live Server: Go Live C abre la página en el navegador. Con cada Ctrl + S, se recarga sola.

Emmet: abreviaturas

Viene con VS Code. Escribimos la abreviatura y tocamos Enter.

Prettier: formato al guardar

  1. Ctrl + , abre la Configuración.
  2. Buscamos “format on save” y tildamos Editor: Format On Save.
  3. En Editor: Default Formatter, elegimos Prettier - Code formatter.

Si está activo, se ve Prettier D en la barra de abajo. Con cada Ctrl + S, ordena la sangría y los espacios. También agrega una barra a las etiquetas que no se cierran: <br> pasa a <br />. Las dos formas son correctas.

Idea clave: para empezar a desarrollar necesitamos un editor de código, un navegador web y una carpeta ordenada para guardar los archivos.

27. Estructura base, títulos y párrafos

La portada de un proyecto, línea por línea

Qué hace cada línea

  • <!DOCTYPE html>: es un documento HTML5. Va primero.
  • <html lang="es-AR"> contiene todo. lang es el idioma: español de Argentina.
  • <head>: datos que no se ven. En las dos <meta>, charset hace que se vean bien los acentos y la ñ, y viewport, que la página se adapte al celular. <title> es el título de la pestaña.
  • <body>: el contenido visible.
  • </head>, </body>, </html> cierran lo que se abrió, con /.
  • Con ! + Enter, VS Code la escribe sola: cambiamos en por es-AR y Document por el título.

Títulos: de h1 a h6

Van del <h1>, el más importante, al <h6>, el de menor jerarquía. Usá un solo <h1> por página y mantené el orden.

  • Párrafo <p>

    Define un párrafo de texto, con espacio arriba y abajo.

  • Salto <br>

    Corta la línea dentro de un texto. No se cierra.

  • Línea <hr>

    Separa dos partes con una línea. No se cierra.

Idea clave: todo documento HTML parte de una estructura base, con doctype, html, head y body. En body van los títulos y los párrafos.

28. Listas, enlaces e imágenes

Y las etiquetas semánticas: header, main y footer

Listas.

Cada ítem va en un <li>. En <ul> (viñetas) el orden no importa; en <ol> (números), sí.

Imágenes.

<img> necesita la ruta del archivo (src) y un texto alternativo (alt) que describa su contenido.

Enlaces.

Con <a>: href es el destino. A otro sitio, la dirección completa (ruta absoluta); a una página nuestra, el nombre del archivo (ruta relativa).

Etiquetas semánticas.

Tienen significado: describen el contenido de cada parte de la página.

Idea clave: listas, enlaces e imágenes organizan el contenido; las etiquetas semánticas dicen qué es cada parte de la página.

29. CSS: la hoja de estilos

Vincular la hoja, selectores, colores y tipografía

  • Selector: indica a qué elemento se aplica el estilo.
  • Propiedad: define qué característica se va a modificar.
  • Valor: el valor que toma la propiedad (un color, un tamaño…).

CSS y HTML

CSS (Cascading Style Sheets) es el lenguaje que define la apariencia visual de una página web. Se conecta con HTML mediante la etiqueta <link>, en el <head>: indica al navegador qué archivo CSS debe cargar.

  • Etiqueta h1

    Selecciona todos los elementos de esa etiqueta.

  • Clase .destacado

    Todos los que tienen esa clase. Se puede repetir.

  • Id #titulo

    El elemento con ese id. Es único en la página.

Propiedades de color y de texto, y qué cambia cada una
colorEl color del texto.
background-colorEl color de fondo.
font-familyEl tipo de letra.
font-sizeEl tamaño del texto.
font-weightEl grosor (normal, negrita).
text-alignLa alineación del texto.
line-heightEl espacio entre líneas.

Idea clave: CSS define la apariencia de HTML y se conecta con <link>. Los selectores eligen a qué elementos se aplica cada regla.

30. Modelo de caja y flexbox

Vistos con las DevTools de Chrome

En CSS, todos los elementos son cajas rectangulares, con cuatro partes:

  • Contenido: texto, imágenes u otros elementos.
  • padding: espacio interno, hasta el borde.
  • border: el borde. 2px solid #2563eb
  • margin: espacio externo, entre cajas.
  1. 1F12, o clic derecho sobre la página → Inspeccionar.
  2. 2La flecha A elige una parte; en Elements (elementos) B se marca su etiqueta.
  3. 3En Styles (estilos) C, sus reglas. Los cambios ahí no se guardan.
  4. 4En Computed (calculado) D, el modelo de caja.

Flexbox.

Alinea elementos en una fila o en una columna. El contenedor flex lleva display: flex y sus hijos son los ítems flex: justify-content los alinea en el eje principal (horizontal), align-items en el eje cruzado (vertical) y gap los separa.

Idea clave: cada elemento es una caja con contenido, padding, borde y margin. Flexbox alinea las cajas; DevTools muestra cómo quedan.

Lámina 25

Cómo funciona una página web

Un servidor envía los archivos al navegador, que los interpreta y los muestra.

  1. Escribimos la dirección de la página.
  2. El navegador se la pide al servidor.
  3. El servidor envía el HTML, el CSS y el JS.
  4. El navegador interpreta los archivos.
  5. Se muestra la página y podemos usarla.

Mientras trabajamos, Live Server hace de servidor en nuestra computadora (127.0.0.1).

Lámina 26

Buenas prácticas iniciales

Desde el primer día

  • Nombres simples, sin espacios ni acentos: mi-sitio.
  • Guardar seguido: Ctrl + S.
  • Archivos ordenados: las imágenes, en la carpeta img.
  • Probar los cambios: con Live Server abierto.

Extensiones de VS Code

  • Instalar: Ctrl + Shift + X, buscar el nombre e Instalar.
  • Live Server: también con clic derecho sobre index.html → Open with Live Server.
  • Prettier: Shift + Alt + F ordena el código sin guardar.

Lámina 27

La estructura, en un segundo

Lo que está dentro de <body> es lo que se ve en la página. El contenido del <head> no se muestra.

Las etiquetas se cierran en orden inverso: lo último que se abrió es lo primero que se cierra. Por eso </body> va antes que </html>.

Los espacios de más no cuentan

Los espacios y Enter de más cuentan como uno solo. Para cortar una línea, va <br>.

Lámina 28

Etiqueta, elemento y atributo

  • Etiqueta: indica el tipo de contenido. Ej.: <p>.
  • Elemento: apertura + contenido + cierre.
  • Atributo: agrega información o configuración. Ej.: class="destacado".

Elementos vacíos

No tienen contenido ni cierre: <img>, <br>, <hr> y <meta>. Lo que necesitan va en sus atributos.

Lámina 28

Listas anidadas y formatos de imagen

Una lista anidada va dentro de un ítem de otra lista, antes del </li>.

Formatos de imagen

JPG: fotografías. PNG: con transparencia, para logotipos. SVG: vectorial, no pierde calidad al agrandarse. GIF: animadas.

Lámina 28

Enlaces: más atributos y rutas

  • target="_blank": en una pestaña nueva (externos).
  • href="mailto:…": abre el correo.
  • href="#contacto": va a la sección con ese id.

Cuidado con las rutas

  • Va siempre la barra /, aunque Windows muestre \.
  • Foto.JPG y foto.jpg son archivos distintos.

Lámina 29

Colores y buenas prácticas de CSS

CSS admite diferentes formatos para definir colores:

  • Nombre en inglés: royalblue.
  • Hexadecimal, el más usado: #2563eb.
  • rgb(236, 72, 153): rojo, verde y azul.
  • rgba(37, 99, 235, 0.7): con transparencia; es #2563eb al 70 %.

El selector * selecciona todos los elementos.

Buenas prácticas

  • Usá clases para lo que se repite, e id solo para un elemento único.
  • Nombres descriptivos y en minúsculas.
  • Una o dos fuentes y buen contraste entre el texto y el fondo.

Lámina 30

Cuánto ocupa una caja y más flexbox

El tamaño total de la caja es la suma de sus partes. Con width: 300px, padding: 20px, border: 2px solid y margin: 30px, el ancho total es:

300 + (20 + 20) + (2 + 2) + (30 + 30) = 404px

Más propiedades de flexbox

  • justify-content: flex-start, center, space-between o space-around.
  • align-items: stretch (por defecto), center o flex-end.
  • flex-direction: column: el eje principal pasa a ser vertical.

Recomendación: separá los ítems con gap, no con márgenes.
